# Ainotate Review (Kiro)

Run:

```bash
AINOTATE_ORIGIN=kiro-cli ainotate review
```

You may append an optional PR URL:

```bash
AINOTATE_ORIGIN=kiro-cli ainotate review <pr-url>
```
